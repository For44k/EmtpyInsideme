# Your cat-themed GitHub profile

## Use on GitHub

1. Create a public repository named for4k (matching your GitHub username).
2. Add README.md and the assets folder from this package to its root.
3. Commit the files. GitHub displays this README on your profile.

GitHub removes custom CSS, so the styled design is included as a PNG image in the README. Its fonts, artwork and cards therefore keep their appearance. The image has descriptive alternative text, and the stack is also written below it.

## Edit your name and design

Open index.html in a browser for the editable HTML/CSS version. The profile name is set to for4k; edit it in index.html and the README image alternative text if needed. The font pairing is Nunito (rounded headings and body text) + DM Mono (small technical labels). Google Fonts requires an internet connection; system fonts are the fallback. Colors, card spacing and mobile styling live in style.css.

After editing the HTML/CSS, replace assets/profile-card.png with a new screenshot of the .profile element to update GitHub's image. The existing PNG is a static snapshot, not a live rendering of the HTML. Your supplied images are preserved in assets/doodle-cats.jpg and assets/pixel-cat.jpg. The pixel-cat landscape forms the profile background, zoomed out to show the full scene across the desktop width with a matching green base below. CSS positions the original doodle cats in opposite corners, so both artworks also appear in the README snapshot. The interface uses transparent glass surfaces with a light 3px backdrop blur, increased to 5px behind the skill section and text-only technology cards.

This package has no build step and no JavaScript runtime dependency. It has not been uploaded to your GitHub account. The username is for4k. No projects, contact details, statistics or external profile links have been invented.
